# 初次問卷

新帳號第一次登入（尚無寵物與生活紀錄）時，會自動進入四步驟問卷。已有資料的舊帳號不會被強制，寵物首頁會顯示「填寫初次問卷」提示。完成或按「稍後再填」後，問卷與首頁提示都不再出現，重新整理停留在問卷網址也會回到寵物首頁；只有從「偏好設定 → 初次問卷」主動點選，才會再次開啟。示範模式不保存問卷。

## 題目

1. **平常的作息**：每週上課／上班天數；上課日與非上課日各自的上床、大約真正睡著、起床時間；非上課日是否用鬧鐘。天數為 0 或 7 時只問存在的那一組。
2. **睡眠與生活感受**（從不／有時／經常／總是）：淺眠、鬧鐘前自然醒且精神好、思緒停不下來難入睡、晚上效率比白天好；能處理壓力、睡醒精神好、有時間照顧自己。
3. **咖啡因、酒精與運動**：最後一杯含咖啡因飲品的時段；每週飲酒頻率，有喝酒才追問睡前三小時內飲酒頻率；運動時段，有運動才追問每週天數與強度。
4. **目標與夥伴**：常見晚睡原因（1–3 項）、最終希望上床時間；尚未領養時選擇寵物並取名。

完成後，上課日（沒有上課日時用非上課日）的上床與起床時間會寫入作息設定的「目前通常上床」「通常起床」，目標寫入「最終希望上床」。達標仍以**上床時間**與事先保存的當晚目標比對，固定可晚 15 分鐘；入睡困難不扣金幣。重新填寫不會改動已保存的每晚目標與金幣。

## 計算方式（MCTQ）

依 Munich ChronoType Questionnaire（Roenneberg 等，2003）的睡眠中點概念，所有時間以跨午夜分鐘計算：

- 睡眠時長 SD ＝ 起床 − 入睡（跨午夜）
- 睡眠中點 MS ＝ 入睡 ＋ SD ÷ 2
- 每週平均睡眠 ＝（上課日 SD × 上課天數 ＋ 非上課日 SD × 其餘天數）÷ 7
- 修正後假日睡眠中點 MSFsc：非上課日睡得比上課日久時，MSF −（SDf − SDw）÷ 2；否則等於 MSF
- 社交時差 ＝ |MSF − MSW|

時型傾向以 MSFsc 描述：早於 03:30 為偏早型，05:30 或更晚為偏晚型，其餘為中間型。**這兩個分界是本產品自訂**，MCTQ 本身是連續數值；這不是醫學分型或診斷。非上課日用鬧鐘起床時結果標示「僅供參考」。沒有非上課日時不計算時型，沒有上課日時不計算社交時差。睡眠時長以「入睡到起床」估算，不等於實際睡著的時數。

睡眠中點與睡眠時長的**標準差**（規律性）需要多天資料，問卷階段只有平日、假日兩組時間，因此不計算；需累積每日紀錄後另行處理。

## 資料處理

- 答案保存在帳號的 `profiles` 資料中。後端重新驗證答案、捨棄未知欄位，並自行重算所有衍生數值，不採信前端送來的結果。
- 產生每日作息目標時，只把整理後的摘要（時型傾向、社交時差、睡眠時數、各題選項文字、晚睡原因）交給 Gemini，原始時間答案不傳送。AI 仍受原本的時間界限限制，不能因問卷一次大幅提早。
- 知識庫新增 K10「睡前飲酒」（NHLBI 健康睡眠習慣），讓 AI 談到酒精時有可引用的來源。

# 好友、小組共養與獎勵

啟動夜泊、登入後，點右側工具列的「好友」。好友頁是單一頁面，沒有分頁：
- **好友列表是主體**：每位好友一張卡，顯示對方小夥伴的頭像、狀態與近七天成績，可移除好友（會先請你確認）；好友三位以上時列表上方可切換排序。頁面上方固定顯示自己的帳號與好友搜尋；有待處理的邀請時，會多出一個邀請區塊，左側「好友」圖示也會出現小紅點。
- **最下方是一行「共養小組：名稱 · 人數 / 5 人」**，點開可建立、加入與管理小組。

**自己的狀態、分享設定與成績在「使用者」頁**（右上角的使用者按鈕）：「向好友分享我的狀態」「讓好友看到我的成績」兩個開關預設關閉，開啟後好友卡才會顯示你的狀態與成績；狀態按鈕（尚未收尾／準備睡了／已起床）要先開啟分享才能按。同一頁也有連續達標、最長連續、近七天達標、3／7／21 晚里程碑徽章與獎勵紀錄。

**目前沒有前端入口、但後端與 API 都保留的功能**（下方章節的規則仍是後端的實際行為）：早安打卡與鼓勵、打卡牆、排行榜（含共養小組範圍）、小組的共養寵物、家具、餵食與金幣紀錄。個人與小組金幣仍由後端照常結算。

若手機仍顯示舊版、看不到好友入口，用同一個夜泊網址開啟 `/update.html`，即可下載並啟用新版後進入好友頁；此入口會保留登入與裝置暫存，不需要清除網站資料。

## 好友與狀態

- 輸入至少三個帳號字元搜尋，送出邀請。對方接受後才成為好友；可以婉拒、取消邀請或移除好友。
- 「向好友與小組分享我的狀態」預設關閉。開啟後自行標記尚未收尾、準備睡了、已起床；十八小時沒更新便顯示尚未更新。
- 狀態是手動標記，不代表系統偵測到入睡。完整生活紀錄、上床時間、私人小紙條不會分享。

## 小組共養

- 每個帳號同時加入一組，最多五人。建立小組並命名共養寵物，再把邀請碼交給朋友。
- 小組與個人的寵物、家具及金幣各自獨立。所有成員可餵食、購買、擺放或收起小組家具。
- 組長可以移除成員、更新邀請碼。組長離開時由最早加入的成員接任；最後一人離開時小組結束。
- 目標夜晚當天十八點前加入的成員，才參與那晚的小組結算；加入之前的紀錄不補發小組金幣。組員離開後仍按當晚的原成員名單核對全員達標。
- 個人達標時，小組另外得到十枚金幣；個人進步獎對應小組五枚。當晚至少兩位成員且全員達標，再給小組二十枚。
- SQLite 交易與唯一獎勵識別碼確保重送不重複發獎，同時購買不會重複買到同一家具或使小組餘額變負。

## 進步與連續達標獎勵

| 條件 | 個人獎勵 |
| --- | --- |
| 符合事前保存目標，保留原有十五分鐘寬限 | 二十枚金幣 |
| 有事前目標但未達標，比該筆回報前七天平均上床時間提早至少十五分鐘；比較期至少三筆 | 十枚金幣 |
| 首次連續三晚達標 | 額外十五枚＋三晚小星星徽章 |
| 首次連續七晚達標 | 額外四十枚＋七晚月亮徽章 |
| 首次連續二十一晚達標 | 額外一百五十枚＋二十一晚星河徽章 |

需先領養個人寵物才能領個人金幣。每晚的達標與進步獎擇一；從進步改為達標只補十枚差額。各連續里程碑每帳號領取一次。未達標或缺填會中斷連續天數，但已領徽章與金幣保留；難入睡或夜醒不扣幣。

這些獎勵在生活紀錄同步到後端時結算，使用伺服器時間與台灣日期。本機離線時可先填紀錄；連線同步成功後才確認進步與里程碑獎勵。重複儲存、刪除後重填，不會重領已結算的獎勵。

既有資料庫的個人獎勵在首次結算時匯入獎勵帳本，保留原已領金幣；舊資料不需重新註冊。SQLite 會自動新增社群資料表。

## 打卡牆與排行榜

- 先保存今天的上床回報，再自願發布早安打卡與最多一百四十字短句。每日一則，可更新或刪除，不會自動公開。
- 好友與目前同組成員可以看見打卡、送鼓勵（後端規則，好友頁目前沒有打卡入口）。打卡不附完整睡眠時間；移除好友或離組後，不再因該關係取得對方的打卡存取權。
- 成績預設不分享，帳號開啟「參加好友排行」後，好友卡才會顯示該好友的近七天達標、連續達標與比前七天提早的分鐘；沒有分享成績的好友顯示「未分享成績」。開關在使用者頁。
- 好友列表可依名字、近七天達標晚數、比前七天提早分鐘或連續達標晚數排序，缺資料的排在最後。後端排行榜 API 仍支援共養小組範圍，好友頁目前只使用好友範圍。
- 進步比較需最近七天與前七天各至少三筆上床紀錄，否則顯示資料不足；正數代表提早，負數代表延後，時間跨午夜計算。

社群操作需連線；頁面開啟時每三十秒自動更新，也可按右上角的「重新整理」。這仍是自行回報的專題原型，未整合自動睡眠偵測或防止使用者捏造生活紀錄的機制。

## 驗證

`npm.cmd run check` 檢查語法；`npm.cmd test` 驗證帳號權限、好友同意、隱私、狀態過期、小組人數與交接、同時消費、進步補差額、連續里程碑、跨午夜日期、打卡存取、排行榜與重新啟動後保存。
